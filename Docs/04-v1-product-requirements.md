## 1. 依据、目标与服务承诺

### 1.1 本轮依据与证据边界

| 依据 | 本文采用的内容 | 证据限制 |
|---|---|---|
| [项目定义](01-project-definition.md) | 解决真实问题、一次一个主要问题、连续档案、行动与跟踪闭环 | 属于产品定义，不证明干预有效 |
| [产品全景与路线](03-product-vision-roadmap.md) | V1 数字使用切入；多人体系、预测及其他年龄领域后置 | 版本方向不等于当前功能 |
| 本轮上层审查，结论已合入上述两份文档 | 补齐服务出口、必要参与、完整结果、专业与运营责任 | 审查建议不是专业认证或用户批准 |
| 归档提取的《沉迷手机需求》《手机使用合约常见问题》 | 家庭联盟、可行性、家长行动、共同计划、任务反馈与调整的骨架 | 统一时长、因果解释、惩罚无害及不会复发等旧断言不继承为规则 |
| 用户校正及设计者推荐 | 第0节的产品事实、长期档案、按需参与和AI主导交付 | 推荐不冒充用户批准，资源未核实不冒充就绪 |

历史提示词和示范只作为资料。未审签的旧条目不能进入正式知识包；不能因为某条旧方法没有被本版选用就将其视为已否定或删除。原资料继续保留，由专业负责人逐项决定后续去向。

### 1.2 要解决的问题

家长常带着“孩子玩手机太久”的结论求助，但实际困扰可能涉及作息、学习、沟通、需求满足或其他需要专业支持的因素。一次回答难以知道行动是否做得到，也无法处理执行障碍、家庭成员不同意或短期改善后的反复。

V1 的产品目标是：在明确适用范围内，把数字使用困扰转化成有来源的理解、合理共同目标、家长能执行的计划和连续反馈；实际约好触达方式与节点，复盘后能够调整，并如实结束为改善、无需干预、退出或其他合适去向。

本版验证四个问题：能否辨别适合继续的家庭；能否形成并执行有针对性的行动；能否兑现授权范围内的持续跟踪；能否用完整结果而非聊天体验评价价值。减少手机时长可以是目标之一，睡眠、必要学习与联系、冲突和自主性等约束同样重要。

### 1.3 对用户可以承诺什么

对外建议表述为：“我们帮助家长了解数字使用困扰，制定可以调整的家庭行动计划，并按实际约定跟踪和复盘；适用条件不足或出现风险时，会暂停普通方案并提示下一步支持。”展示当前开放方式、验证期或收费说明、可用功能与渠道、退出及适用范围。没有真人服务时不展示虚构排班或审核时限。

不能承诺治好、绝不复发、孩子必然服从、无限期人工服务、真人即时或全天候在线。方案生成、消息发送、一次打卡、周期到期都不等于问题解决。结束本轮服务应留下原因、结果证据和下一步，不能以“已给过建议”结案。

## 2. 用户、角色与范围

### 2.1 目标用户和参与者

面向国内中文家庭，定位不将港澳台家庭一概排除；实际登录、通知与现实支持资源的地域可用性据实显示。服务主题是未满18岁孩子的家庭教育问题，不设未经依据的统一最低年龄。具体知识与行动按年龄、发展阶段及问题适配；低龄主要通过家长行动获得支持，不套用青少年方法。

主端是现有微信小程序“小树英助手”。家长主账号发起和推进问题；孩子可经邀请用自己的微信账号进入本问题的轻量参与页，也可拒绝、暂不回复或退出。V1不要求全家注册，不建设完整多人私人长对话及复杂共享空间。工作人员使用最简内部管理后台，用户无需再使用另一套Web产品。

| 角色 | 可以做的事 | 边界 |
|---|---|---|
| 家长主账号 | 描述观察、维护必要档案、确认目标方案、反馈、邀请孩子、管理提醒和资料请求 | 不代替孩子作直接确认，不读取未获准共享内容 |
| 受邀孩子 | 了解邀请与可见范围、接受或拒绝参与、表达本问题意见、对共享计划及本人任务表态和反馈 | 只见本人提交和明确共享内容，不读取家长原话，不强迫注册或承担任务 |
| 未注册成员 | 线下协商，由家长注明来源后转述 | 转述、未回复、拒绝和本人直接表态分开 |
| 内容与质量人员 | 检查知识来源、年龄、规则和示例，发布版本并抽查 | 内容审核不等于逐方案真人审批，未知旧断言不能直接发布 |
| 产品维护人员 | 管理开放范围、处理反馈与资料请求、观察质量和成本 | 按目的和权限访问；没有真人服务不承诺回访或专家接单 |
| 有真实承接条件的异常复核人员 | 在明确范围内处理需人工的异常及安全事项 | 能力、负责人和时限真实成立才启用，不是全天候救援 |

普通方案及实质调整默认经过系统规则、来源及安全校验，再由家长确认准确版本。仅审核规则明确要求人工、且有实际承接时才走复核；否则说明当前不能完成该判断，可缩小目标或提示现实支持，不制造空的“专家正在审核”。

首次使用以简短清楚的隐私告知和必要确认说明服务、长期档案、AI处理与共享范围。不满十四周岁儿童及敏感资料按适用要求确认；不同意可选提醒不保存为同意。V1不设置“所有18岁资料人工核验”的常规流程，不默认收身份证或完整生日。

年龄有声明时点、来源及不确定性，供方法适配和必要边界检查。成长、关系变化或后续本人独立服务时复核相应依据；不因满18岁自动清空历史，也不自动把家长记录移交孩子。

### 2.2 范围处置矩阵

| 项目 | V1 处置 | 原因及去向 |
|---|---|---|
| 手机、平板、电脑、游戏机等数字使用困扰 | 纳入首场景 | 按用途、功能影响和家庭情境理解，旧资料排除电脑的边界不沿用 |
| 睡眠安排、替代活动、家长示范和沟通配合 | 作为同一个案内的必要行动纳入 | 只服务当前数字使用目标，不发展为独立疗程 |
| 家庭联盟与共同计划 | 纳入，可选计划形式 | 不要求全家参加，不强制签合约、盖章或惩罚 |
| 不确定是不是数字使用问题 | 允许先了解和分诊 | 不能据此承诺其他场景已有成熟服务 |
| 正常发展或无需干预 | 提供已审核解释并结束 | 保留无需干预结论，不能算为干预改善 |
| 必要信息或参与条件不足 | 等待或缩小到家长能执行的目标 | 不把未知、不愿回答与拒绝协商合并 |
| 明显超范围的情绪、严重冲突、功能受损等 | 边界说明、专业复核或转介 | 不在 V1 内继续一个未具备承接能力的专业流程 |
| 家长独立创伤、夫妻治疗、其他年龄领域 | 本版不提供完整服务 | 记录候选需求，按适用支持渠道分流 |
| 孩子轻量参与／完整家庭协作 | 受邀孩子参与本问题纳入V1，完整共同与私人空间后续增强 | 拒绝或撤回可退回家长能承担的路径，不强迫注册 |
| 多个个案并行执行 | 不纳入 | 候选问题保留；当前主线可受控切换 |
| 实时调停、语音、临床诊断、危机救援 | 不纳入 | 基础安全中断与支持信息仍为 V1 必需能力 |
| 预测、类似案例推荐、训练模型、内容社区 | 延后 | 本版积累有来源的个案记录，不能宣称已具备这些能力 |
| 支付、订阅、退款、复杂机构平台 | V1验证期不建设 | 小范围免费验证为推荐，后续商业化按真实需求决定 |

## 3. 用户旅程与关键出口

### 3.1 普通适用路径

1. 家长进入小程序，查看范围、当前开放方式和资料用途，登录并作必要确认。验证期可邀请或灰度开放，数量按质量和系统能力配置，不写死总家庭数。
2. 建立必要家庭资料，描述困扰，选择数字使用或“还不确定”。已描述内容可复用，但需区分家长原话、提取候选和已确认资料。
3. 自然交流与少量结构化确认并用，完成适用性、安全、基线和必要条件了解。一次只追问当前最关键的缺项；允许暂存、跳过可选项、拒答和退出。
4. 呈现“目前知道什么、来源是什么、仍不知道什么、建议先解决什么”。家长修正后确认当前主要问题；发现其他问题只存候选，不开多条执行线。
5. 将家长期待转成可观察目标，记录诉求来源、需求、条件与阻力。可邀请孩子直接表达或线下协商后注明转述；孩子拒绝时采用家长能承担的目标，缺必需信息则等待。
6. 生成结构化方案草案，展示家长行动、家庭协商、可选家庭计划、任务、反馈与复盘日期、保护条件和暂停条件。拒签合约可改普通行动计划。
7. 系统校验结构、来源、适用条件及安全，通过后家长确认准确版本。普通方案不逐份等真人签批；按需异常另走真实分支。执行和提醒方式分别记录，只有可履约授权渠道才标主动跟踪已启用。
8. 执行中可看任务、记录做了多少、未做原因、现实变化与成员反馈；安全入口始终可见。到期按真实授权和额度提醒，必要时由获单独授权的人工渠道回访。
9. 按问题、阶段及家庭约定反馈和复盘，不统一强制天数。对照基线、目标、约束和证据，决定继续、调整、等待、暂停、转介或维护，日期到期不代替判断。
10. 调整产生新方案版本，经必要审核及家长确认再执行。旧版本、调整理由和前后证据保留，不能覆盖成“最初就是这样”。
11. 达到约定条件后进入维护，长度按实际问题和家庭约定确定，记录稳定条件、信号、节点与重开入口，不把统一天数当疗效周期。
12. 根据实际证据和家长确认完成结案摘要。复发可从历史进入，重新检查安全、适用性、现状和授权，创建关联原个案的新一轮个案，原结案快照保留。

### 3.2 必须走通的例外路径

| 触发情境 | 当下行动 | 后续状态与承诺 |
|---|---|---|
| 基线不支持需要干预，家长仍有担忧 | 解释依据和不确定性，允许补充证据或复核 | 可结束为无需干预；不硬造一个行为目标 |
| 无法估计时长或说法冲突 | 记录未知及各来源，可约短期观察再补 | 等待信息；不选一方当真，不把空值变成零 |
| 孩子拒绝合约，家长愿意改变 | 记录拒绝的具体对象，改家长行动计划 | 条件充分则继续；不把拒绝合约当作拒绝服务 |
| 必须直接了解成员意见但当前拿不到 | 说明还缺什么，约线下协商并给安全的准备材料 | 等待参与；可缩小目标，不伪造已取得同意 |
| 非数字使用问题成为主要因素 | 停止按原解释继续，专业复核并说明本版边界 | 适用新主线可切换；超范围则分流或转介 |
| 未同意提醒或渠道不可用 | 仍可执行计划并主动反馈，显示站内待办及真实提醒能力 | 不虚报已启用主动跟踪，只有实质依赖联系的步骤才等待渠道 |
| 用户暂停、退出或撤回联系授权 | 立即停止未来普通提醒，说明对本轮服务的影响 | 暂停或退出；不为完成率继续联系 |
| 已到两次约定节点都无反馈 | 核对授权和实际尝试记录，再由运营确认 | 满足条件才记失访；结果仍未知 |
| 出现安全信号或不利变化 | 随时中断普通方案，显示审核过的支持信息 | 安全挂起与人工复核；队列不作为应急救援 |
| 模型或网络故障 | 保留已提交状态，展示处理中、失败或重试入口 | 不编一个看似成功的回复；不丢原反馈 |

## 4. 个案、证据与状态语义

### 4.1 最小业务对象

家庭、人物与账号分开理解。V1一个家长主账号维护家庭，可按需关联受邀孩子账号及多名孩子必要资料，但一个家庭最多一个当前主要个案。候选问题只保存主题、描述、发现时间、来源、优先理由及待处理状态，不展开执行计划。切换主线必须展示原进度、为何切换与提醒影响，家长明确确认后整体生效。

个案保存主要问题、阶段、适用性依据、专业包版本、目标、基线、方案版本、任务、反馈、复盘、联系安排、风险和结果。反馈不是任务勾选的同义词；复盘不是把反馈重写一遍。原始记录、修正事件、派生摘要和决策分开保留可追溯关联。

每条可用于判断的信息须包含：涉及谁、谁提供、发生／观察时间、记录时间、来源类别、原文或引用、确认与有效状态。来源类别至少区分本人陈述、家长观察、家长转述其他成员、手工录入的设备记录、工作人员记录与 AI 假设。V1 不直接接入设备数据；手录“设备显示 3 小时”仍须注明录入者、设备和时间范围。

“已确认”表示相应提供者确认了这条陈述或记录，不表示客观真相已被独立证实。家长确认“孩子说愿意”仍是家长转述。AI 假设不能因被重复总结而升级；矛盾来源并列展示，不静默合并。`UNKNOWN`（不知道）、`NOT_COLLECTED`（未收集）和 `DECLINED`（明确拒答）必须可区分。

### 4.2 个案状态和阶段是两个维度

| `status` | 用户可理解的意思 | 约束 |
|---|---|---|
| `OPEN` | 正在推进 | 有生效方案与反馈安排；主动提醒和家长主动返回分开，不把拒绝可选提醒当作禁止执行 |
| `WAITING` | 等待必要条件 | 必须给原因、下一步、责任方和复核节点；不能称正在有效执行 |
| `PAUSED` | 已暂停 | 保留原阶段；不发普通提醒；恢复需重新核对条件与授权 |
| `LOST_CONTACT` | 约定节点未收到反馈，已按规则确认失访 | 不等于拒绝、无效或改善；保留返回入口，不持续骚扰 |
| `SAFETY_HOLD` | 当前优先处理安全支持 | 普通建议、任务与普通提醒停止；只有安全流程可推进 |
| `CLOSED` | 本轮服务已结束 | 必须有结案原因和结果快照；不能由模型独立结束 |

`phase` 固定为 `INTAKE`（进入）、`ASSESSMENT`（了解判断）、`GOALS`（目标）、`PLANNING`（方案）、`EXECUTION`（执行）、`REVIEW`（复盘）、`MAINTENANCE`（维护）。暂停、等待和安全挂起保留进入前阶段；结案也保存最后阶段。无需干预可从判断阶段直接结案，不能为走全流程虚构执行记录。

等待原因为 `INFORMATION`、`PARTICIPATION`、`PROFESSIONAL_REVIEW`、`CONTACT_CHANNEL`。建议用户端只突出当前主阻塞，详情保留同时存在的其他条件及其解除证据；全部必要条件满足才恢复。旧主要个案因优先级切换暂停时使用 `PAUSED(reason=PRIORITY_CHANGED)`，保留原 `phase`、方案与反馈。

结案原因限于 `STABLE_IMPROVEMENT`、`NO_INTERVENTION_NEEDED`、`USER_WITHDREW`、`OUT_OF_SCOPE`、`EXTERNAL_HANDOFF_COMPLETE`。暂停不是结案原因，失访也不是。结束免费试点或观察周期不能自动结案为稳定改善；服务负责人应告知后续安排并与家长确认适用去向。

### 4.3 结果、转介和风险独立记录

| 维度 | 状态及含义 | 不能推断的内容 |
|---|---|---|
| `outcome` | `IMPROVED` 改善；`NO_CHANGE` 未见变化；`WORSENED` 恶化；`UNKNOWN` 证据不足 | 已结案不等于改善；降低时长不必然整体改善 |
| `referral` | `PROPOSED` 已建议；`ACCEPTED` 愿意尝试；`CONTACTED` 已实际联系；`CONNECTED` 已确认建立服务衔接；`DECLINED` 明确拒绝；`UNREACHABLE` 经实际尝试未能衔接 | 建议、同意或打开链接不等于衔接；衔接不等于病情或家庭状况改善 |
| 风险事件 | `OPEN` 已触发；`UNDER_REVIEW` 正复核；`RESOLVED` 由授权人员按规则形成处置结论 | 用户说没事、点击确认、模型低分不能独立解除安全挂起 |

结果必须带观察窗口、对照目标、证据来源、评定者与不确定性；保留历次变化，主看板展示最新结果。没有随访证据时留 `UNKNOWN`。无需干预通常没有干预后结果；不能为了凑改善将其记为 `IMPROVED`。转介每次联系尝试有时间、渠道、来源及结果，不得覆盖旧尝试。

### 4.4 关键状态改变的控制

| 动作 | 发起／确认者 | 必须满足的条件 |
|---|---|---|
| 确认问题与目标 | 家长确认，必要时专业复核 | 展示依据、来源和缺项；缺必要条件不能继续 |
| 启用方案 | 家长确认具体版本 | 规则与安全校验通过、必要参与成立；仅明确要求人工的分支需真实复核，提醒能力据实显示 |
| 普通复盘与实质调整 | 实际参与者反馈、规则校验 | 对照基线，新版本重新校验及家长确认，异常才按需复核，旧版不静默改写 |
| 主线切换 | 家长确认；风险可先中断 | 事务性完成旧个案暂停、新主线与未来提醒变化；不能出现两条执行主线 |
| 暂停／退出／撤回联系 | 家长可主动发起 | 无需说服用户继续；异步发送前再次核对最新授权和状态 |
| 失访 | 运营确认 | 连续两个约定节点无反馈，且至少一次实际授权联系尝试；授权、发送失败与是否触达分别记录 |
| 安全恢复 | 授权专业复核人员 | 依据已审签规则、记录结论与限制；恢复前核对计划和家长意愿 |
| 维护与结案 | 家长确认、按规则核对证据，异常实际复核 | 未改善、恶化、未知不改成成功，本轮结束不清空长期档案 |

AI 可以提出候选改变，不能独立改事实、确认目标、启用／替换方案、结案、认定实际转介或解除安全挂起。时间触发器只能建立待反馈／待复核事项，不能代替这些决定。

## 5. 基线、目标、方案和反馈的内容标准

### 5.1 基线与适用性

了解具有代表性的近期情况，具体观察窗口按问题与已审核方法确定，记录工作日／休息日差异、数字用途、娱乐与必要使用、时长估计及来源、停止使用的困难、睡眠作息、学习到校与日常功能、冲突、线下活动、情绪担忧、家长既往措施及效果。允许没有精确时长；必要时约一段家庭能承担的轻量观察，保留尚未获得的状态。不能为了完整字段逼用户估一个确定值。

不是每个维度都强制量化。专业包定义必要项、条件必要项、可选项、何时允许保留未知以及何时必须等待或复核。无合适依据不引入量表，不给“成瘾分数”或诊断标签，不把超出统一小时数作为充分判据。家长描述的情绪和行为用于范围判断与安全关注，不转成临床结论。

### 5.2 目标与可行性

每个个案有一个主要目标，可以有数个共同服务于它的行动。目标写清基线、期望变化、观察方式、复盘日期和保护条件。例如“在协商的晚间时段按约结束娱乐使用，同时不影响必要作业联系，观察入睡和争执变化”，具体时点由家庭和专业规则确定。不得默认所有家庭需要同一屏幕时长或一律禁用设备。

目标须包含家长行为；孩子责任来自本人确认或有来源的协商转述，未同意的仍待协商，不替孩子承诺。可行性讨论至少覆盖需求、动机、能力、时间和资源、阻力及家长配合。0—10 主观量尺可作为表达工具，附“家长自评／转述”，不当诊断、直接准入阈值或孩子真实动机的证据。

### 5.3 方案与任务

方案草案包含问题理解及不确定性、共同目标、选择理由、可执行行动、相关成员和信息来源、预计阶段、任务、轻反馈与复盘节点、联系安排、可能阻力、调整与暂停条件、专业包及版本。方案页区分草案、校验失败、待家长确认、已生效、已替换、已暂停及按需人工复核，不将草案呈现为已开始服务。

“实质调整”至少包括目标或保护条件、责任人、任务内容或负担、激励／违约条款、风险边界、适用人群或专业方法的变化，不能通过改名规避校验和重新确认。仅把一次反馈／复盘时间在已发布规则允许的小幅窗口内变更，且不增加任务负担、联系次数或风险时，可单独重排而不产生实质调整方案；仍需家长主动确认、记录原时间和原因、取消原提醒并重新检查渠道及频次。该窗口必须由专业包审签定义；没有已发布窗口就按实质调整重新校验，不自行猜一个“可延几天”。

实质调整产生新版本，重新校验并由家长确认后替换。新草案未确认前，旧版仅在仍适用、安全且家长愿意时继续；发现原方案不适用或风险则暂停相关行动。需要人工的异常才实际复核，不因创建草案自动停掉所有正常行动。

首次建议只有 1—3 个优先任务，允许按真实需要增减；每项明确由谁做、具体行为、何时或在何情境做、如何观察、需要谁配合、遇到阻力怎么办。任务状态区分待开始、进行中、部分完成、完成、未执行、暂停与取消；逾期只是时间属性，不自动记失败。V1反馈可由家长或获准孩子提交，保留真实作者和可见范围。

家庭合约是可选的计划形式，不作为服务门票。可采用普通行动计划；可以没有激励或违约条款。若选择家庭计划，应明确家长责任、双方约定如何修改与退出，不用羞辱、暴力、剥夺基本需求或未经审签的强制措施。电子勾选或家长录入不代表孩子具有法律意义的签署；V1 不做印章和电子签约服务。

### 5.4 反馈、复盘与维护

轻反馈询问完成程度、没做或难做的原因、观察到的变化、成员反馈和新担忧，允许“还不知道”“暂不回答”。正式复盘对照基线、目标与保护条件，分清执行不足、方案不适配、信息需要修正与新主要问题；不能自动将没完成归咎于家长或孩子。

若时长下降但冲突、睡眠或必要活动出现重要不利变化，不能直接评价整体改善，应重新了解并触发相应复核。方案调整至少说明什么证据导致调整、保留什么、改变什么与下次观察什么。保护条件的专业判定标准来自已审核专业包，不在本 PRD 编造临床阈值。

维护长度按个案、规则和家庭约定确定，不统一规定天数。进入时写明稳定条件、最低观察、何时回来、复发信号和联系方式；结束时与原目标对照。未收到反馈保持未知，不推断稳定。复发返回时先重新分诊，不能自动沿用旧方案、旧年龄适用性和旧触达授权。

## 7. 提醒、反馈与持续跟踪

### 7.1 节点及提醒方式

每个生效方案有家长认可的反馈和复盘节点，按问题、阶段、负担和实际约定确定，不统一强制天数。站内待办需用户主动打开；离站提醒需平台真实许可。`tracking_mode`区分`USER_INITIATED`（主动返回）与`AUTHORIZED_REMINDERS`（相应节点已有许可），不能把前者记成主动触达。

拒绝可选提醒仍可执行、反馈和看历史；只有当前步骤实质依赖已约定联系又无替代时才等待渠道，不把可选订阅许可作为所有方案生效前提。

微信按实际主体、模板和许可能力安排，一次同意不代表长期无限发送，未知资格不当可用，未授权不联系。节点、渠道和真实外呼结果分别保存。

频率随方案约定、跨渠道合并。设计者推荐默认普通主动联系每日最多1次、同日任务合并，21:00—08:00（Asia/Shanghai）安静；家长可调整时段。改变频率仍需明确约定与平台能力，不无限催促；主动交流不计普通提醒。

### 7.2 真实状态与条件性人工服务

区分意图、未发、抑制、平台受理、明确失败、结果未知及业务反馈；受理不表示阅读或改善，未知不盲重试或跨渠道重复联系。撤回取消尚未开始的普通发送，在途和已受理无法保证收回。

许可不足时保留站内节点，说明依靠主动返回，可请求下次重新选择，不创建假定有人承接的回访。实际提供真人服务且用户同意时才显示真实人员、时段与约定；本文不预设真人排班或统一审核时限。

失访需连续两个约定节点无反馈、至少一次真实授权联系尝试，再由有权人员核对。无许可、发送失败、无人处理或结果未知本身不足以判失访；没有联系条件保留反馈缺失／未知，不无限提醒，不把退出或失访记改善。

## 8. 专业治理、安全与人工运营

### 8.1 专业包与审核责任

专业包是可以审签与追溯的一组适用条件、必需信息、分诊规则、目标约束、行动方法、内容模板、风险中断与转介规则、复盘和结案条件、示例及反例。每个条目有来源、适用年龄、责任人、审核日期与版本，不把旧文档或模型生成当成已审核来源。

包状态建议为草稿、待审、已发布、已停用。只有已发布版本进入真实个案；个案和方案固定引用版本，不在后台一改就静默影响所有家庭。普通新版本经回归样例检查后发布，新个案用新版本；老个案若需迁移，列影响、复核适用性并对实质方案变化重新确认。发现重大安全问题可立即停用相关内容，暂停受影响方案并由人员处置，保留原因和通知证据。

内容发布明确知识与规则审核责任，检查来源、适用范围、风险与反例。普通个案以AI按规则交付为主；人工用于知识维护、抽查及有真实条件的异常处理，不默认逐方案签批。实际人工投入如实记角色和耗时，无人或超范围不承诺专家接单。

### 8.2 安全优先与转介

安全检查发生在进入、每次新输入、生成前后、反馈、复盘及恢复时，不能只在注册勾一次。出现已审核规则所列的即时伤害担忧、疑似暴力虐待、严重失控或超出服务能力的线索时，先停止普通建议和任务推进，再展示固定审核内容与可获得的现实支持路径；模型不可继续自由发挥。

建议支持卡明确：“当前情况需要优先获得现实中的适当支持；如果存在当下伤害危险，请优先寻求当地紧急服务或具备相应能力的医疗等支持，不要等待应用回复。”正式措辞、风险等级和处置步骤由专业负责人在上线前审签。本文不提供未经核实的电话、机构、合作承诺或自动报警能力。界面不保证即时真人回应，仅在实际提供时公布相应时段，队列不是应急救援。

转介资源发布前核验地区、服务范围、实际联系方式、服务时间、费用说明来源和最近核验时间。只有公开信息时标注“公开信息，非合作机构”；没有真实合作方不能使用合作表述。用户可以拒绝转介；不羞辱、不强迫、不将拒绝变成默认安全已解除。需要安全例外处理信息时，按实际审签规则和适用依据记录范围与原因，并向用户作适当说明。

只有实际确认建立外部服务衔接才可记录 `CONNECTED`，普通外部衔接完成结案还需确认本轮去向和后续责任；不要求收集外部机构敏感诊疗全文。用户报告已接通电话只能说明相应联系情况，不能自动记录已接受专业服务或改善。

### 8.3 AI 的明确边界

AI 在当前阶段和已发布专业包内提出追问、理解、总结、目标或方案候选。输出须能指向所用条目和证据，区分已知、未知与假设。服务校验身份权限、必需字段、内容边界、引用版本、关键状态和安全规则后才呈现完整回复；校验不通过显示可理解的失败或转人工状态，不能编造替代数据。

AI 不诊断、不作疗效保证、不虚构孩子原话或设备数据、不以“专业建议”隐去来源、不替家长确认计划，不独立发送外部联系或决定安全解除。输出中“孩子可能……”仍是候选解释；用户确认自己这样想也不构成孩子真实心理事实。

V1 采用持久化异步文字生成，显示处理中、成功、失败和恢复查询，不承诺实时 token 流式。模型不可用时仍可看已有方案、提交事实反馈、暂停退出、查看安全支持和提出权利请求；有新风险的反馈须先走安全检查。不能为了保持对话流畅而跳过专业校验。

已有 AI 任务运行时，仍可提交新消息和反馈。服务端先保存并立即进行规则安全检查；新的风险信号不得等上一条 AI 回复结束才处理。旧上下文的回复停止应用，按最新资料重新安排允许的生成；排队、预算耗尽或模型故障均不能封住风险信息入口。未经确认已保存的输入须明确显示失败并保留客户端草稿。

## 9. 长期档案、隐私、纠错与删除

### 9.1 多年连续档案

必要家庭与个人档案长期保存，支持两年、五年及更久后的使用：成员和关系变化、重要事件、历史问题、基线、目标、历版方案、执行、复盘、有效／无效做法及未解决事项均有来源。结案、暂停、失访和长期未登录不自动清空，也不按统一一年期限删除。

档案不只是覆盖更新的AI摘要。关键资料有来源、时间、确认者、版本和纠错关系，能回到重要依据。旧观察、转述和AI假设带时间及不确定性，重用时核对现状；多年历史按当前问题和权限选取，不每次全塞模型。

原始聊天与档案分开管理，V1不设置结案满一年统一清空任务。之后若需压缩清理，先明确规则与用户选择，保留获准的必要档案及依据；不能把清理原聊天等同清空长期资料。

### 9.2 简明告知、参与和纠错

首次使用简明说明服务、长期档案、AI处理及共享范围，不逐句弹审批。不默认收身份证、学校、精确地址；儿童与敏感资料按适用要求确认，营销、训练、公开案例不包含在默认用途中。

孩子只进入本问题的有限参与页，不自动看家长私人对话。提交前明确家长可见范围，可以拒绝或停止参与。V1不建完整私人长对话，但基本隔离和安全保护必须存在；可能涉及家人伤害的信号先安全检查，不自动向相关家人广播。

有权主体可查阅、更正和导出；争议保留为争议，纠错使摘要、上下文及受影响方案同步失效／重算。导出核验身份、限时下载，不含无权内容或内部模型思维。

### 9.3 分层保存与删除

| 资料 | 当前规则 | 来源及限制 |
|---|---|---|
| 必要长期档案 | 持续保存，支持多年回溯，不随结案或一年到期自动删除 | 用户明确要求；持续服务目的和有效依据下保存，用户可管理和删除 |
| 原始对话与关键证据 | 与档案分开，V1不按结案一年统一清空 | 原文删除需标记，不能假装仍可读取；必要档案保留按用户选择及范围 |
| 临时模型上下文／调试副本 | 只留核查实际必需范围，随来源撤回删除 | 不为复现重复囤积全文，供应商侧边界需核实 |
| 访问及安全操作记录 | 设计者建议1年，不含完整对话 | 说明谁何时查阅／修改／删除；相关网络日志不少于六个月，其他法定记录单独处理 |
| 主动删除申请 | 核验范围后7天内清除应用在线数据 | 7天是处理时限，不是聊天自动到期；核验受阻及时说明 |
| 恢复备份 | 滚动50天 | 防误删灾难恢复，不代替长期档案；最后含被删数据的副本最迟在在线清除后50天过期，期间不作新业务使用 |

删除分单条原话、整理条目、个案及账号／家庭资料。只删原聊天而保留整理档案时须明确展示并让用户选择；整案／账号删除覆盖衍生、长期档案副本、索引、模型上下文及导出，不能转存来规避删除。立即停止受影响新使用和待执行任务，按范围逐项记完成、等待、例外或失败。

恢复先重放独立删除清单，旧会话失效，核对当前权限、停用规则及未知外发，不能复活已删资料、旧同意和旧提醒。回执区分在线清除、备份过期、供应商及真实保留例外。备份50天不妨碍主库保存五年前资料：今天的备份会包含仍在主库的历史。

持续服务用途和访问依据需要维护；撤回相应用途、服务终止或资料不再必要时依法处理。不以沉默、结案或固定计时器自动否定全部档案，也不承诺脱离用户意愿和服务目的无条件保存一切。

依据：[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)、[网络安全法](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm)。需落实到真实处理方式和上线文本，文档不代替法律及平台验收。

## 11. 指标、分母与试点判断

### 11.1 固定人群与计数

以一次邀请制批次为观察队列，记录批次和截止日期。`N_screened` 为同意参与筛选的去重家庭数；处置分别为已准入、等待条件、明确不适用／拒绝本轮、未完成筛选／未知，四类相加必须等于原数。明确不适用要有范围依据，用户拒绝要有本人决定；没有回复不能记拒绝。

`N_entered` 为已取得必要授权并创建正式个案的进入数，包含后续无需干预、超范围、退出及安全转介。家庭数和个案轮次数分别统计，重开不能冒充新家庭。`N_started`为家长确认且生效的方案个案数；另记`N_proactive_started`为相应节点确有授权提醒能力的个案数。主动返回可以执行，但不混入主动触达兑现分母，草案不算启动。`N_due` 为截止时已到约定反馈／复盘节点的个案或节点数，必须在指标名写清计数单位。

个案状态六类必须互斥对账；结果四类以最新可用证据为快照相加等于 `N_entered`，没有可评价证据也要分配 `UNKNOWN`。转介是独立维度，与状态和结果重叠，不能把它们加在一起当总数。结案原因只在 `CLOSED` 内对账。维护未到期、延期和仍等待的人保留在分母并说明尚未可观察。

权利请求及到期清除优先于追求永久逐案统计。资料清除前按已告知且允许的统计目的保存批次级汇总快照，不含家庭／个人链接；同时登记删除影响和统计截止时点。原进入分母不能因删除而静默缩小，无法继续评价的结果列 UNKNOWN。若连最小汇总也不具备保存条件，报表明确标记因资料删除无法完整核对，不补造记录、不输出看似完整的可比改善率。

### 11.2 最小指标字典

| 指标 | 分子／分母与证据 | 解读限制 |
|---|---|---|
| 范围判断完整率 | 有范围、安全与必要条件结论的个案／`N_entered` | 结论完整不等于专业判断已验证正确，另由复核记录质量 |
| 有效启动率 | `N_started`／`N_entered`，按家长确认并生效的方案事件 | 不排除无需干预、退出或超范围以美化转化；主动返回不冒充离站提醒 |
| 主动提醒启动 | `N_proactive_started`／`N_started`，按实际许可及节点安排 | 只反映已具备相应联系条件，不表示已送达或完成服务 |
| 节点反馈率 | 到期且收到有效反馈的节点／全部到期节点 | 未做任务但提供真实障碍也属于反馈；发送量不是分母 |

| 触达兑现 | 在约定窗口内实际完成授权联系尝试的节点／承诺应主动联系的节点 | 平台受理、触达未知、用户回应分列；不能写成阅读率 |

| 服务出口 | 各结案原因／全部已关闭个案；另报暂停、等待、失访及未关闭数 | 外部衔接和无需干预不计为干预疗效 |
| 转介进展 | 各实际阶段人数／有转介建议的个案，并保留拒绝与未知 | 各阶段不是互斥漏斗总和，明确展示当前状态与事件 |

| 交付成本与意愿 | 每进入／每启动／每复盘个案的人工分钟与实际费用；意愿按实际回答者及未回答数 | 免费试点意愿不等于付费转化，未知成本不能补零 |

改善的操作定义必须在本个案目标确认时约定，并在专业包内可接受：有来源的现实变化达到约定方向／程度，必要保护条件未出现重要不利变化，真实发生的人工复核与用户评价差异明确保留，不假定每案都有人工结论。任何统一“降到几小时就有效”或未经验证的总体疗效及格线都不在本版设定。

### 11.3 开放范围与验证判断

推荐先小范围免费验证，按真实质量、反馈、费用及负载逐步开放。邀请、灰度和临时数量限制可配置并留变更；不以固定家庭总数或逐方案真人排班作为产品成立条件。家庭数、进入者和个案轮次分别统计。

自然观察判断、确认、执行、反馈、复盘、实际需要的调整、维护、出口及参与同意／拒绝。没有真实情境则记证据不足，可用标明的演练验功能，不为凑数诱导调整或编造效果。

升级前核对全部去向和不利结果；知识和输出质量、实际跟踪、长期档案回溯成立；无未处置严重安全隐私问题，费用可承受。功能完成或少量故事不证明普遍有效。

开放方式调整时说明已有家庭后续安排；本轮结束或停止提醒不默认撤销长期档案用途，用户仍可管理有权资料，也可导出、清理或退出相关用途。
